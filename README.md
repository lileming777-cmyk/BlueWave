# BlueWave 蓝调音乐

蓝色原生 Mac 音乐播放器。SwiftUI 界面，支持常见音频与 DSD 文件、内嵌/LRC 歌词、自动匹配封面、可保存的播放列表。

支持索尼常见 DSF / DFF 高解析音乐在电脑端播放（DSD 转 PCM）。Mac 版可在本机构建安装；Windows 1.0.4 源码同步更新，需在 Windows 原生环境重新打包。旧版 1.0.0 Windows 安装包仍包含已移除的听写功能，请勿当作新版发布。

## 安装与启动

- 环境：Apple Silicon Mac，macOS 14 或更新版本。
- 双击 `BlueWave-1.0.4-arm64.pkg` 安装到「应用程序」，或解压应用 ZIP 后将 `BlueWave.app` 拖入「应用程序」。
- 内置 FFmpeg 和 ffprobe，无需安装 Python、Homebrew 或其他运行环境。播放与读取本地歌词无需联网；缺少本地封面时可在线匹配，设置中可关闭。
- 本地构建使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。向其他 Mac 分发前建议由维护者完成签名与公证；系统可能对下载的未公证应用提示验证。

## 使用

1. 点击「导入音乐」选择文件或文件夹，也可拖放多个文件/文件夹。重复导入不会重复创建歌曲。
2. 双击歌曲播放。空格播放/暂停，⌘←/⌘→ 切歌，⌘O 导入，⌘L 收藏当前歌曲。
3. 点击侧边栏「播放列表」旁的 `+` 新建列表；右键歌曲添加到列表，右键列表改名或删除。列表中可拖动排序。删除列表和移除歌曲都不会删除原始音乐。
4. 点击底部歌词按钮：自动读取同名 LRC、内嵌歌词；缺失时显示暂无歌词，可自行提供同名 LRC。已读取歌词支持导出。自动听写已移除，旧听写缓存不再读取。
5. 设置中可独立开启「音量统一」和「歌曲平滑过渡」（1–8 秒），并选择输出采样率与精度。两项默认关闭，保留原始播放习惯。
6. 输出采样率可选跟随音源、44.1/48/88.2/96/176.4/192 kHz。精度可选 16/24 bit 软件量化或 32 bit 浮点。设置在下次播放/进度跳转时生效。
7. 封面优先取内嵌图片，其次歌曲同名图片、cover/folder/front/封面等同目录图片。专辑和艺人优先读取文件标签，缺失时参考 CUE、文件夹和文件名；推断来源显示在音频信息面板。缺少本地封面时，为当前播放歌曲和可见的封面卡片通过 Deezer / MusicBrainz / Cover Art Archive 在线匹配歌手、专辑和歌名；歌手和歌名均匹配才采用；无可靠匹配时使用同专辑封面，仍无图则显示歌名。缓存后不重复下载。不会联网改写音乐标签。
8. 标题栏右侧「…」提供「清空并重新导入」。先选择新文件/目录，确认后才清空当前播放列表或资料库记录。原始音乐保留；清空前自动备份曲库到数据目录 `Backups/`。取消文件选择不会清空。

## 音频说明

| 类型 | 格式 | 验证情况 |
|---|---|---|
| 常见压缩音频 | MP3、AAC/M4A、Ogg/Vorbis、Opus、WMA | 已验证解码 |
| 无损与 PCM | FLAC、ALAC、APE、WAV、AIFF、WavPack、TTA、AU、CAF | 已验证解码，APE 使用真实音源 |
| DSD 高解析音频 | DSF、DFF | 已验证解码；转换为 PCM 输出 |
| 索尼 ATRAC 系列 | OMA、AA3 / ATRAC | 已编译解码器，尚待对应样本验证 |

以上为 Mac 版验证结果，样本范围见 `docs/VALIDATION.md`。加密或带 DRM 的音乐不在已验证支持范围内。
- DSF/DFF 转换为 PCM；默认 DSD 使用 176.4 kHz，普通音源跟随采样率（上限 192 kHz）。不支持原生 DSD、DoP、独占输出或位完美保证。
- 硬件最终输出格式取决于系统音频设置和设备，音频信息面板中的采样率是软件解码输出。16/24 bit 会量化后进入系统浮点音频链路。
- 音量统一采用单遍动态响度调整（−18 LUFS，真峰值 −1.5 dB，LRA 11），不会修改原始文件；不等同于离线测量整个曲库的 ReplayGain。
- 音频按播放时长缓冲，后台补充队列；不会因每个小块音频等待界面线程而停供。此优化不保证消除设备、音源或网络之外的所有卡顿。
- 自动过渡同时播放两个流并交叉调整音量，单曲循环时不启用。手动跳过/拖动进度会结束过渡。

## 封面下载与隐私

自动下载默认开启，可在设置中关闭。仅查询歌手、专辑和歌名，不上传音频、文件路径或曲库。外部服务会接收请求及网络地址。下载失败不会影响播放；切歌或离开封面卡片时取消不再需要的请求。歌手匹配依赖文件标签或本地推断，不是声纹识别。元数据错误可能导致找不到或错配封面，可关闭自动下载并提供本地图片。

封面来自 Deezer / MusicBrainz / Cover Art Archive；缓存保留来源 URL。接口公开可访问不代表图片获得自由再发行许可，图片版权属于相关权利人。下载封面仅用于播放器展示，不随应用、源码或安装包分发。请遵守来源服务条款与当地法律。

## 数据

本地曲库、收藏、列表：`~/Library/Application Support/BlueWave/library.json`。封面保存在 `Covers/`。旧曲目会在需要封面时重新读取元数据，无需清空曲库。在线没有图片或网络暂不可用时使用同专辑封面，仍无图则显示歌名；音频信息面板可重新匹配。旧版 `Transcripts/` 文件保留但不再读取。外接卷断开时保留资料库记录，重新连接后可播放。损坏的库文件会保留原件并提示，禁止静默覆盖。

## 从源码构建

需要 Xcode 命令行工具、Python 3（仅测试格式工具需要）；首次下载解码器源码需要网络。在项目目录执行：

```sh
bash scripts/build-decoders.sh
swift test --disable-sandbox
bash scripts/build.sh
```

官方 FFmpeg 源码归档包含在源码包 `third-party/ffmpeg/`，脚本优先使用。源码包不含个人音乐、封面缓存、索尼固件、设备序列号或私人曲库。

输出：`dist/BlueWave-1.0.4/BlueWave.app`、安装包、应用 ZIP 和对应源码 ZIP。测试音频输出需要可用的本机音频设备及系统权限。

开发时可用 `BLUEWAVE_DATA_DIRECTORY=/path/to/separate-profile` 启动应用二进制，隔离曲库且不注册系统媒体键，避免测试覆盖主资料库。

### 1.0.4 封面匹配

缺少内嵌和本地封面时，向 Deezer（优先）和 MusicBrainz（后备）发送歌手＋歌名联合查询；只采用两项均匹配的结果，专辑名用于优先排序。下载图片与来源信息保存在本机，可在歌曲信息里查看匹配项和来源链接。仅发送文本标签，不上传音乐或文件路径。

无歌曲封面时，使用同歌手、同已知专辑的本地或已缓存封面；仍无图则显示蓝底歌名。未知专辑不共用封面。在线服务覆盖和可用性有限，可能仍无法匹配；下载到的图片不随开源源码或安装包分发，版权归相关权利人。

Mac 1.0.4 提供应用、PKG 和源码包。Windows 1.0.4 为同步源码及离屏测试，本轮未生成新的 Windows EXE；旧 EXE 不包含这些修复。
